{Open-Source Lagrangian Particle Simulation Library (R/C++)}%
{WindsOfChange}%
{Aug 2024 — Present}%
{}%
{%
\begin{itemize}
  \item Developing C++ library implementing Lagrangian particle dispersion, atmospheric turbulence, and fluid flow over complex hilly terrains with forest canopy, based on analytical models (Massman \& Weil 1999; Finnigan \& Belcher 2004).

\cventry{\href{https://github.com/zkdavis/Tleco}{github.com/zkdavis/Tleco}}%
{Open-Source Physics Simulation Library (Python/Rust)}%
{Tleco}%
{Jan 2024 — Sep 2024}%
{}%
{%
\begin{itemize}
  \item Multiscale/multiphysics simulation toolkit combining Rust and Python interfaces for modeling relativistic particle distributions via Fokker-Planck equations coupled with radiative transfer.
  \item Implements numerical PDE solvers, particle distribution algorithms, and spectral calculation methods for relativistic plasma physics.
\end{itemize}
